# 咲耶ジャンプバグ フィーチャーリスト

改修はここに番号（F1, F2, …）を振って並べ、**1機能につき1ブランチ・1PR** で入れる。
`jumpbug.naoblock.jp` は main から GitHub Pages で配信しているので、**PR をマージした時点で本番に出る**。

## 進め方

1. 改修をこのリストに足す（番号・やりたいこと・状態）
2. main からブランチを切る（例: `feature/f1-jump-hint`）
3. 実装して PR を出す。PR には変えた点・確かめた点・スクリーンショットを書く。
   見た目や操作が変わるときはアーティファクトの試遊版も更新してリンクを貼る
4. レビューしてマージ → 本番に反映。このリストの状態を「完了」にして PR 番号を書く

状態: `未着手` / `作業中` / `完了` / `見送り`

## v1.0（初版ローンチ）

2026-09-26 公開。main のコミット `e21934c` 時点。

入っている機能:

- ⌐◨-◨カー（🚙型ピンクのドット絵）で跳ねながら進む、本家ジャンプバグと同じ強制スクロール
- 4ゾーン（城下町 → 忍びの洞窟 → 天守 → 鳥居の丘）、チェックポイント、残機、燃料
- ジャンプ長押しで高く跳ぶ・空中で2回まで連続ジャンプ・バックで戻って拾える
- CNP 11体の救出とロスター、コイン、敵（撃つ／踏む）
- バルカン（スマホは最初から自動連射。タップで切り替え、長押しで手動射撃）
- スマホ操作: 左半分の浮動式バーチャルスティック（咲耶Nounラリーと同じ）、右半分／JUMP ボタンでジャンプ
- 画面中央の薄い一時停止ボタン、効果音・BGM（WebAudio）
- ゲームオーバー／ゴールの演出動画（咲耶スクランブルと同じ作り）
- ランキング TOP10（Google スプレッドシート score3 + Apps Script）
- X シェア（画像カード付き）、OGP、アプリ用アイコン、縦持ちの案内画面
