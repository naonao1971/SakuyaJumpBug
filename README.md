# 咲耶ジャンプバグ

レトロゲーム「ジャンプバグ」風の横スクロール。⌐◨-◨カーは地面や屋根に触れるたびに勝手に跳ねる。
画面は本家と同じく**強制スクロール**で、一定の速さで勝手に進む。何も押さなければ車は画面について走り、
→で前へ出て、←でバックする。画面は止まらないが、画面の中は自由に動けるので、
通り過ぎたコインやCNPも左端に消える前なら取りに戻れる（咲耶スクランブルと同じ）。車は常に前を向き、
自動連射も前へ撃ち続ける。壁と画面の左端にはさまれるとミス。
CNPを拾いながらゴールの鳥居を目指す。公開URLは `https://jumpbug.naoblock.jp/`（GitHub Pages。独自ドメインは `CNAME` で指定）。
姉妹作: [咲耶スクランブル](https://sakuya.naoblock.jp/) / [咲耶Nounラリー](https://rally.naoblock.jp/)

- 単一ファイル（`index.html`）。画像は `assets/cnp/*.png`（CNP 11体）と `assets/sakuya_pilot.png`（咲耶の表情5コマ）。
  どちらも咲耶スクランブルから複製したもの
- アイコン（`apple-touch-icon.png` 180px / `favicon-32.png` 32px）はこの作品専用。`tools/mkicon.py` で作る
  （要 Pillow）。咲耶スクランブルの三角形と同じく形だけで見せる: 暗い四角＋金の枠の中に、
  屋根に ⌐◨-◨ を乗せた 🚙 型の車が機首を上げて跳ね上がるシルエットを、マゼンタの塗り＋金の縁取り＋
  淡い光で描き、後ろに金の点で跳ねた軌跡を添える（水平な横向きの車だと咲耶Nounラリーと見分けがつかないため）

```
python3 tools/mkicon.py apple-touch-icon.png favicon-32.png
```
- 音はWebAudioで生成しているので、音声ファイルは不要

## 操作

| 入力 | キーボード | スマホ |
| --- | --- | --- |
| 前進・バック | ← → / A D | 画面の左半分を押したまま左右に倒す |
| ジャンプ（押している間は高く跳ぶ） | SPACE / ↑ / Z | 画面の右半分を長押し、右の JUMP、またはスティックを上に倒す |
| バルカン（ショット） | X で撃つ / V で自動連射の切り替え | バルカンボタン（▶▶▶）: 短くタップで自動連射のオン/オフ、押し続けている間は撃つ |
| 一時停止 | P / Esc | 画面の真ん中の薄いボタン（咲耶スクランブルと同じ。止めている間ははっきり出る） |
| 音 | M | 右上のボタン |

**バルカン**は咲耶スクランブルと同じ自動連射つき。スマホでは最初から自動連射オン（PC はオフ）で、ジャンプに集中できる。
スマホのボタンは1つにまとめてある: 短くタップ（250ms 未満）で自動連射のオン/オフ、押し続けている間は手動で撃つ。
自動連射がオンの間はボタンをマゼンタで縁取る。

ボタンの中身はすべて 11×11 ドットのアイコン（`index.html` の `ICONS`）。バルカンと JUMP は同じ大きさ。

ジャンプは押した瞬間に手応えが返るようにしてある。跳ねた直後に押せばその場で大ジャンプ、
落ちている最中に押せば次の着地で大ジャンプ（予約）。短く押しただけでも `JUMP_HOLD`
フレームぶんは長押し扱いになり、長く押すほどさらに高く跳ぶ。

**連続ジャンプ:** 空中でジャンプを押すと、その場でもう一度跳ぶ。着地までに `AIR_JUMPS`（既定2）回まで。
使い切ってから押すと、次の着地で大ジャンプする予約になる。空中ジャンプの強さは `PHYS.airJump`。
目安（地面から上がる高さ）: 何もしない約70px / 空中1回で約175px / 空中2回で約280px。

スマホの移動は姉妹作「咲耶Nounラリー」と同じ**浮動式バーチャルスティック**。
左半分のどこでも、触れた場所にスティックが出る。最初に倒すまでは左下に点線の影と
「左半分のどこでも押したまま倒す」の一行を出す（走り直すたびに出し直す）。
プレイ中は iOS のピンチズームを打ち消す（1本指の動きは打ち消さない）。
バルカン/JUMP が出ない端末では右上のコントローラーのボタンで出し入れできる。

## 調整ポイント

- `CAR_SPRITE` / `CAR_COLORS` … ⌐◨-◨カーのドット絵（30×19ドット、1文字=1ドット）と色。🚙 型の四駆の屋根に ⌐◨-◨ が乗っている

- `SCROLL` … 強制スクロールの速さ（ゾーンごと。px/フレーム）
- `PHYS.maxBack` / `PHYS.accelBack` … バックの速さと切り返しの速さ
- `PHYS` … 重力、跳ねる強さ、速度。長押ししたときの最大ジャンプは約230px、建物は最大200px
- `FUEL_DRAIN` … 燃料が減る速さ（満タンで約60秒）。燃料缶は `buildLevel()` の末尾
- `buildLevel()` … 地形・敵・コイン・CNPの配置。シードを変えると別のコースになる
- CNPはコースの奥や難所ほど高ランク（得点 100〜1500）のキャラを置いている

## Xシェア

咲耶スクランブルと同じ作り。結果の画像カード（1200×675。⌐◨-◨カー・スコア・CNP救出数・
どこまで進んだか・11体のロスター）を作り、対応端末では OS の共有シートへ画像と文章を渡す
（X を選べば画像付きで投稿できる）。共有シートが無い環境では、画像を保存してから投稿画面を開く。
カードは `buildShareCardCanvas()`、文章は `buildShareText()`。

Claude のアーティファクト（試遊版）では共有シートを呼べないので、文章だけの投稿リンクにしてある。
